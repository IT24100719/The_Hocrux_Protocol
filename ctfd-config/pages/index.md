# The Horcrux Protocol

*Department of Mysteries — Case File. An isolated training lab; every system and all data here are synthetic.*

Six fragments of a dark contingency lie hidden across six systems. Recover them, in order, and carry them home.

## How it works

- **Six stages, HX-01 → HX-06**, each a different discipline — steganography, web, cryptography, forensics, networking, and Linux privilege-escalation.
- Stages **unlock in order**: solve one to reveal the next.
- Each stage hides a **fragment** — a flag shaped like `HORCRUX{...}`. Submit it on that challenge to score.

## Scoring

- Stages are worth **100–400 points**, rising with difficulty.
- You begin with a **100-point balance**, so help is within reach from the very start.

## Hints

- Every stage carries **three hints**: a gentle nudge, then a technique, then a near-answer.
- Hints **cost points** — roughly **5% / 20% / 50%** of the stage's value — and unlock **in order**, so the cheap nudge always comes before the expensive spoiler.
- Spending points on hints **lowers your score**, so reach for them only when you're truly stuck.

Open the **[Challenges](/challenges)** and start with HX-01.
